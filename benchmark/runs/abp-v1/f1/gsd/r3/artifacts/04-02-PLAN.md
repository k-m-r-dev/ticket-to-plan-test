# S02: Todo CRUD + filter + validation

**Goal:** Implement POST/GET/PATCH/DELETE /todos with completed query filter, title/body validation, shared JSON error envelope, and RFC3339/UUID fields per SPEC.
**Demo:** After this: curl CRUD and filtered list with correct status codes

## Must-Haves

- All five todo endpoints match SPEC statuses and bodies; validation_error/not_found/internal_error codes; empty/overlong title and empty PATCH/bad completed query return 400

## Proof Level

- This slice proves: manual

## Integration Closure

Handlers use shared AppState DB pool and error type; list filter uses completed query

## Verification

- Structured error responses only; no extra telemetry required

<tasks>
- [ ] **T01**: Models + shared error envelope _(30m)_
  Define Todo JSON model (id UUID string, title, completed, created_at/updated_at RFC3339 UTC). Implement error JSON {error:{code,message}} with codes validation_error, not_found, internal_error. Centralize IntoResponse mapping for 4xx/5xx.
  - Files: `apps/todo-api/src/models.rs`, `apps/todo-api/src/error.rs`
  - Verify: cargo check; unit-test error JSON shape if trivial
- [ ] **T02**: Create + list + get handlers _(60m)_
  POST /todos: body {title, completed?}; trim title; length 1..=200; default completed=false; server UUID + timestamps; 201 full Todo; invalid title → 400 validation_error. GET /todos: optional completed=true|false; invalid → 400; 200 JSON array. GET /todos/:id: 200 or 404 not_found.
  - Files: `apps/todo-api/src/routes/todos.rs`, `apps/todo-api/src/app.rs`
  - Verify: cargo check; manual curl create/list/get or temporary smoke
- [ ] **T03**: Patch + delete handlers _(45m)_
  PATCH /todos/:id: subset of title/completed; empty body → 400; title rules when present; update updated_at; 200 or 404. DELETE /todos/:id: 204 empty or 404. Wire all routes on router.
  - Files: `apps/todo-api/src/routes/todos.rs`, `apps/todo-api/src/app.rs`
  - Verify: cargo check; manual curl patch/delete
</tasks>
