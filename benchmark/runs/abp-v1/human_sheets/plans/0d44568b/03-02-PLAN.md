# S02: Todo CRUD + filter + validation

**Goal:** Implement POST/GET/PATCH/DELETE /todos with completed query filter, title validation, shared error envelope, UUID ids, RFC3339 timestamps.
**Demo:** curl CRUD and filtered list with correct status codes

## Must-Haves

- All SPEC endpoint behaviors and status codes work; validation_error/not_found/internal_error codes used; empty/overlong title and empty PATCH and bad completed query return 400; missing ids return 404; DELETE returns 204

## Proof Level

- This slice proves: Manual curl or early service tests against handlers

## Integration Closure

Todos routes mounted on same router as /health; persistence via sqlx

## Verification

- Handler errors map to structured JSON error envelope
